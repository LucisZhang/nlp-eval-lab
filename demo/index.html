Triage playground

measured

~200 real CFPB complaint narratives (class-stratified sample), each scored by every available tier plus the router's cascade decision.

Tier A and Tier B2 (DistilBERT int8) run live in-browser via WebAssembly, approximate and clearly labeled below. Tier B1 (no ONNX export) and Tier C (an API model) remain precomputed; all LLM responses are precomputed from committed receipts (no live API).

Select a complaint from the list to see per-tier responses and the router path.

Every number traces to results/runs.jsonl — append-only, committed. Tier B panels backfilled 2026-08-12; the one remaining pending slot (Tier B1 yearly drift series) was descoped by owner and stays labeled.
